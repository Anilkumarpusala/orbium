---

## Key Highlights & Features

- **Architectural Dark Visual Identity**: Deep architectural black (`#0B0B0C`), warm editorial cream (`#F4F2ED`), muted metadata slate (`#71717A`), and single-accent Hyper-Orange (`#FF4400`).
- **Interactive Ambient Canvas**: Pointer-reactive, high-performance HTML5 WebGL/Canvas fluid particle field responding to inertia and mouse velocity with 60 FPS requestAnimationFrame loops.
- **Micro-Texture Overlay**: Hardware-accelerated fixed SVG film-grain noise filter (`opacity: 0.04; pointer-events: none`).
- **Kinetic Custom Cursor**: Smooth lerp interpolation with dynamic badge expansion (`VIEW PROJECT` on case studies) and magnetic spring physics on interactive elements.
- **3D Perspective Tilt**: Depth-based dynamic tilt with smooth return physics on case study feature cards.
- **100% Real Photography**: Zero AI artifacts — curated high-resolution photography via Unsplash.
- **Production Contact Suite**: Interactive budget selection chips, multi-service toggles, client-side validation, dual UTC/IST availability clock, and direct routing to `anilmcqueen@outlook.com` with instant 1-click clipboard copy.
- **Enterprise SEO & Protocols**: Comprehensive JSON-LD structured schemas (`Organization`, `Service`, `LocalBusiness`, `FAQPage`, `AggregateRating`), Open Graph, Twitter cards, `robots.txt`, and XML sitemap.

## Local Development

Launch directly with any static file server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```

Then visit `http://localhost:8000`.
